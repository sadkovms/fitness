# 📥 Установка и запуск NutriVision AI

## 🎯 Самый простой способ (для Windows)

1. **Скачайте и установите Node.js**
   - Перейдите на [https://nodejs.org](https://nodejs.org)
   - Скачайте LTS-версию (18.x или выше)
   - Установите (просто нажимайте "Далее")

2. **Запустите проект**
   - Найдите файл `start.bat` в папке проекта
   - **Дважды кликните** по нему
   - Готово! Браузер откроется автоматически

## 🍎 Для macOS / Linux

1. **Установите Node.js**
   ```bash
   # Через Homebrew (macOS)
   brew install node
   
   # Или скачайте с https://nodejs.org
   ```

2. **Сделайте скрипт исполняемым**
   ```bash
   chmod +x start.sh
   ```

3. **Запустите**
   ```bash
   ./start.sh
   ```

## 🔧 Ручная установка (если скрипты не работают)

### Шаг 1: Откройте терминал в папке проекта

**Windows:**
- Откройте папку проекта
- В адресной строке проводника введите `cmd` и нажмите Enter

**macOS/Linux:**
```bash
cd /путь/к/папке/проекта
```

### Шаг 2: Установите зависимости

```bash
npm install
```

Это создаст папку `node_modules` (может занять 1-2 минуты)

### Шаг 3: Запустите сервер

```bash
npm run dev
```

### Шаг 4: Откройте в браузере

Перейдите по адресу: **http://localhost:3000**

## 📦 Запуск собранной версии (без dev-сервера)

Если хотите запустить оптимизированную версию:

```bash
# Установите сервер для статики
npm install -g serve

# Запустите
serve dist
```

Откройте: **http://localhost:3000**

## ❓ Частые проблемы

### "Node.js не найден"
- Убедитесь, что Node.js установлен
- Перезапустите терминал после установки
- Проверьте: `node --version`

### "npm install не работает"
- Проверьте интернет-соединение
- Попробуйте: `npm cache clean --force`
- Удалите папку `node_modules` и `package-lock.json`, затем снова `npm install`

### "Порт 3000 занят"
- Закройте другие приложения, использующие порт 3000
- Или измените порт в `vite.config.js`

### "Белый экран в браузере"
- Откройте консоль разработчика (F12)
- Проверьте ошибки
- Попробуйте очистить кэш браузера (Ctrl+Shift+R)

## 🌐 Доступ с других устройств

Приложение доступно по локальной сети:

1. Узнайте IP-адрес компьютера:
   - **Windows:** `ipconfig` (ищите "IPv4")
   - **macOS/Linux:** `ifconfig` или `ip addr`

2. На другом устройстве (телефон, планшет) откройте:
   ```
   http://192.168.X.X:3000
   ```
   (замените на ваш IP)

## 📱 Требования

- **Node.js:** 18 или выше
- **Браузер:** Chrome, Firefox, Safari, Edge (последние версии)
- **Место на диске:** ~200 МБ (включая node_modules)
- **Интернет:** нужен только для первой установки
