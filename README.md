# 🥗 NutriVision AI — Анализ питания по фото

Интерактивный веб-прототип приложения для анализа питания с помощью AI.

## 📦 Структура проекта

```
nutrivision-ai/
├── index.html              # Точка входа HTML
├── package.json            # Зависимости проекта
├── vite.config.js          # Конфигурация Vite
├── tsconfig.json           # Конфигурация TypeScript
├── src/
│   ├── main.tsx            # Инициализация React
│   ├── App.tsx             # Главный компонент с навигацией
│   ├── index.css           # Глобальные стили (Tailwind)
│   ├── components/
│   │   ├── Dashboard.tsx       # Главная страница
│   │   ├── FoodAnalysis.tsx    # AI-фотоанализ
│   │   ├── Diary.tsx           # Дневник питания
│   │   ├── Reports.tsx         # Аналитика и отчёты
│   │   └── Profile.tsx         # Профиль пользователя
│   └── data/
│       └── foodData.ts         # Данные (блюда, нутриенты, графики)
└── dist/                   # Готовая сборка (после npm run build)
```

## 🚀 Быстрый запуск

### 1. Установите Node.js (если ещё не установлен)

Скачайте с [nodejs.org](https://nodejs.org/) (версия 18+)

### 2. Откройте терминал в папке проекта

```bash
cd nutrivision-ai
```

### 3. Установите зависимости

```bash
npm install
```

### 4. Запустите в режиме разработки

```bash
npm run dev
```

Откройте в браузере: **http://localhost:5173**

## 📦 Запуск готовой сборки

Если хотите запустить уже собранную версию:

```bash
# Установите сервер для раздачи статики
npm install -g serve

# Запустите
serve dist
```

Откройте: **http://localhost:3000**

## 🛠 Доступные команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Dev-сервер с горячей перезагрузкой |
| `npm run build` | Продакшн-сборка в папку `dist/` |
| `npm run typecheck` | Проверка TypeScript |

## 📱 Функции приложения

- **🏠 Главная** — кольцо калорий, макросы (БЖУ), AI-рекомендации, стрик
- **📷 AI-анализ** — симуляция фото-сканирования с распознаванием блюд
- **📖 Дневник** — приёмы пищи, трекер воды, интервальное голодание
- **📊 Отчёты** — графики, витамины/минералы, тренд веса, паттерны
- **👤 Профиль** — цели, настройки, интеграции, экспорт данных

## 🔧 Технологии

- React 18 + TypeScript
- Vite (сборщик)
- Tailwind CSS 4 (стили)
- Framer Motion (анимации)
- Recharts (графики)
- Lucide React (иконки)

## 📋 Системные требования

- Node.js 18+
- Современный браузер (Chrome, Firefox, Safari, Edge)
- ~50 МБ свободного места
